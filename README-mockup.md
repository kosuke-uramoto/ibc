# IBC ローカルモックアップ

## 最初に行うこと
1. https://ibc:8890/cms/wp-admin/ で「外観 → テーマ → IBC」を有効化。
2. 「外観 → モックアップの準備」でデモデータを追加。次の土曜日の午前・午後と関連ニュースが公開されます。
3. https://ibc:8890/ を開く。

## クライアント向け実演
- 「オープンキャンパス」で午後の開催回を開き、鉄道の体験内容を変更して更新。
- TOP、OC一覧、鉄道ページ、関連ニュース詳細を再読み込みして同じ変更を確認。
- スマホ幅では下部に直近の開催予定へのリンクを表示。
- 学科の体験内容を空欄にすると、その学科への掲載対象から外れます。
- 午前・午後は別々の開催回です。次回表示は日時順の最初の回です。

## 構成
静的HTML：ルート、oc、news、course。共通CSS/JS：assets。
WordPress：cms。今回の管理機能はibcテーマのfunctions.phpに集約。
テーマを変更するとOC管理・配信機能が止まるため、本番では専用プラグインへの分離を推奨。
公開投稿のみ配信。終了日時が過ぎた回を予定から除外。中止回は一覧に残し次回案内から除外。
APIは /cms/?rest_route=/ibc/v1/feed を利用し、パーマリンク設定に依存しません。
最新ニュースは6件。過去のニュースはWordPress側へリンク。
各ページを再読み込みした時点で反映。リアルタイムのプッシュ更新は行いません。

## 今回の範囲
骨組みの動作確認用。本文・日時・学科別プログラムは仮情報です。
フォーム、申込者・残席管理、学科別集合場所、受付期間、承認フローは未実装。
NEWSは自動生成せず、記事で関連OCを選ぶとその最新情報を末尾に表示。
本番公開前に正式コンテンツ・URL・キャッシュ・権限・保守・アクセシビリティの設計を行います。
WordPress本体、wp-config.php、既存テーマ、データベースは作成処理では変更していません。

## ファーストビュー・ナビ
TOPに現行IBCサイトのメインビジュアル2枚を参照するスライダーを追加。画像は現行サイトのCDNから読み込むためネット接続が必要です。出典：https://www.ibc.ac.jp/ （2026-09-08確認）。
自動切替は5.5秒。前後・ドット・停止ボタン・スワイプに対応。動きを減らす端末設定では自動再生しません。
全静的ページとWordPress詳細に共通ナビとメニューを配置。資料請求・個別相談・アクセスは仮案内のダイアログのみで、フォーム送信はありません。

## OCのイメージ画像
OC編集画面の「イメージ画像（任意）」で1枚を選択・アップロードし、投稿を更新します。ブロックエディターでは右側の投稿設定内にあります。画像の差し替え・削除も同じ場所で行えます。
TOPの次回OC、OC一覧、学科ページ、OC詳細、関連ニュースのOC枠に反映します。画像なしの場合は画像枠を表示しません。画像は縦横比を維持し、切り抜きません。代替テキストはメディアライブラリで設定できます。
