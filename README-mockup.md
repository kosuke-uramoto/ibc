# IBC ローカルモックアップ

## 最初に行うこと
1. https://ibc:8890/cms/wp-admin/ で「外観 → テーマ → IBC」を有効化。
2. 「外観 → モックアップの準備」でデモデータを追加。次の土曜日の午前・午後と関連ニュースが公開されます。
3. https://ibc:8890/ を開く。

## クライアント向け実演
- 「オープンキャンパス」で午後の開催回を開き、鉄道の体験内容を変更して更新。
- TOP、OC一覧、鉄道ページ、関連ニュース詳細を再読み込みして同じ変更を確認。
- スマホ幅では下部に直近の開催予定へのリンクを表示。
- 学科の体験内容を空欄にすると、その学科への掲載対象から外れます。
- 午前・午後は別々の開催回です。次回表示は日時順の最初の回です。

## 構成
静的HTML：ルート、oc、news、campuslife、course。共通CSS/JS：assets。
WordPress：cms。今回の管理機能はibcテーマのfunctions.phpとinc配下に実装。
テーマを変更するとOC管理・配信機能が止まるため、本番では専用プラグインへの分離を推奨。
公開投稿のみ配信。終了日時が過ぎた回を予定から除外。中止回は一覧に残し次回案内から除外。
APIは /cms/?rest_route=/ibc/v1/feed を利用し、パーマリンク設定に依存しません。
最新ニュースは6件。過去のニュースはWordPress側へリンク。
各ページを再読み込みした時点で反映。リアルタイムのプッシュ更新は行いません。

## 今回の範囲
骨組みの動作確認用。本文・日時・学科別プログラムは仮情報です。
フォームはデモとして実装済み。申込者・残席管理、学科別集合場所、受付開始日時、承認フローは未実装。
NEWSは自動生成せず、記事で関連OCを選ぶとその最新情報を末尾に表示。
本番公開前に正式コンテンツ・URL・キャッシュ・権限・保守・アクセシビリティの設計を行います。
デモ投稿・フォーム・固定ページ・関連設定はデータベースに保存しています。

## ファーストビュー・ナビ
TOPに現行IBCサイトのメインビジュアル2枚を参照するスライダーを追加。画像は現行サイトのCDNから読み込むためネット接続が必要です。出典：https://www.ibc.ac.jp/ （2026-09-08確認）。
自動切替は5.5秒。前後・ドット・停止ボタン・スワイプに対応。動きを減らす端末設定では自動再生しません。
全静的ページとWordPress詳細に共通ナビとメニューを配置。資料請求・個別相談は各デモフォームへのリンク、アクセスは仮案内のダイアログです。

## OCのイメージ画像
OC編集画面の「イメージ画像（任意）」で1枚を選択・アップロードし、投稿を更新します。ブロックエディターでは右側の投稿設定内にあります。画像の差し替え・削除も同じ場所で行えます。
TOPの次回OC、OC一覧、学科ページ、OC詳細、関連ニュースのOC枠に反映します。画像なしの場合は画像枠を表示しません。画像は縦横比を維持し、切り抜きません。代替テキストはメディアライブラリで設定できます。

## OC申込デモ（2026-11-17追加）
- Contact Form 7 6.2.5。PHP 8.3以上・WordPress 7.1以上が必要です。
- 共通フォームは1件。OCの「申込プログラム・受付設定」でプログラムを追加・削除し、公開／更新します。選択肢と紹介内容が連動します。
- OC詳細の下部にフォームを表示。上部の「このOCに申し込む」は同じページ内のフォームへ移動します。関連NEWSの申込リンクもOC詳細内のフォームへ進みます。旧申込専用ページの有効な開催回リンクは詳細へ転送します。
- 受付停止・中止・締切後・開催開始後・プログラム未登録の回は受付しません。空の締切は開催開始時刻です。
- フォームを開いた後にプログラム・開催日時が変わった場合は再読み込みを求めます。
- 入力→確認→修正→完了まで操作可能。メールはコード側でも停止し、申込内容のDB保存は行いません。架空データを使ってください。
- 595相当のデモは面談希望あり（高校3年、大学・短大生、社会人のみ）、592相当は面談希望なしです。
- 現行2フォームの入力項目・選択肢を確認して再現。郵便番号からの住所自動入力は未実装。生年選択は参照フォームと同じ2015〜1991年です。
- 本番メール設定、申込履歴保存、残席管理、スパム対策の運用設定は本デモに含みません。
- 初期セットアップは inc/setup-registration.php をWordPress読込み後にCLIから実行済みです。フォーム・ページ・サンプルOCはDBに入るため、Gitだけではスタッフ環境に複製されません。
- 参照: https://www.ibc.ac.jp/oc/form/index-sn-595.html / https://www.ibc.ac.jp/oc/form/index-sn-592.html

## NEWS / CAMPUS LIFE（2026-11-17追加）
管理画面「投稿」から記事を追加し、カテゴリ「NEWS（お知らせ）」または「CAMPUS LIFE（学校生活）」を選んで公開します。両方にチェックすると両枠に掲載されます。
TOPは各カテゴリの公開日順で最新3件。各一覧は最新6件を表示し、過去の記事はカテゴリ別WordPress一覧へ進めます。未分類の記事は両枠の対象外です。新規投稿の初期カテゴリはNEWSです。
現行TOP掲載のNEWS3件・CAMPUS LIFE3件を再現しました。ジモキャン記事は両分類共通のため実投稿数は5件です。タイトルと日付を合わせ、本文はデモ用要約と元記事リンクを登録しています。全文・画像の移行は行っていません。ジモキャンの日付は記事詳細ではなくTOPの表示日（11月17日）に合わせています。
Gitでスタッフに共有する場合、投稿・カテゴリはDBの共有か、WordPress読込み後に inc/setup-editorial.php をCLIで実行する必要があります。元記事URLをキーに二重登録を防ぎます。

## 資料請求・個別相談デモ（2026-11-19追加）
- 資料請求： https://ibc:8890/cms/?pagename=req
- 個別相談： https://ibc:8890/cms/?pagename=consul
- 現行サイトの /req/ と /consul/ の入力項目・選択肢に合わせて、それぞれCF7フォームを用意。共通ナビから開けます。
- 資料請求：資料一式／願書のみ、氏名・フリガナ、生年月日、性別、学校・勤務先、学年・区分、住所、メール、電話、希望学科、質問。
- 個別相談：来校／オンライン、希望日・時間、氏名・フリガナ、学校・勤務先、学年・区分、メール、電話、質問。希望日は現行サイトに合わせ任意。指定時は過去日を受付不可としています。
- 入力→確認→修正→完了を操作できます。メールは追加設定とコードの双方で停止し、入力内容は保存しません。架空の情報でお試しください。
- 郵便番号からの住所自動入力、予約枠・空き状況管理、Zoom連携は未実装です。
- スタッフ環境へはDBを共有するか、CF7を有効にしてWordPress読込み後に inc/setup-inquiry.php をCLIから実行してください。設定済みフォームは更新されるため、独自に編集した内容がある場合は実行前に確認してください。
- 参照した項目は docs/reference-req.json と docs/reference-consul.json に記録しています。
